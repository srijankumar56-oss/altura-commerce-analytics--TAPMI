# Altura Commerce Analytics Dashboard

## Overview

This project analyzes customer behavior, product performance, delivery efficiency, customer lifetime value (CLV), anomaly detection, and product lifecycle trends for Altura Commerce.

Developed as part of the Data Odyssey 2.0 competition.

---

## Business Questions Addressed

### Product & Customer Analysis
- Product category performance
- Customer geographic distribution
- Revenue contribution analysis

### Operations Analysis
- Delivery time trends
- Regional delivery performance
- Online vs In-Store channel comparison

### Customer Analytics
- Customer Lifetime Value (CLV)
- Delivery delay impact on retention
- Customer segmentation

### Advanced Analytics
- Sales anomaly detection
- Product lifecycle modelling
- Age-group profitability analysis

---

## Tools Used

- SQL
- Power BI
- DAX
- Excel

---

## Key Insights

- Computers generated the highest revenue contribution.
- Delivery time reduced significantly over time.
- Delayed deliveries negatively impacted customer lifetime value.
- 829 matured products were identified.
- 51K unusual orders were automatically flagged through anomaly detection.
- In-store purchases showed significantly higher average order value than online channels.
